# Проверка PDF перед печатью

Страница /proverka-pdf.html отправляет один PDF в /php/tools/pdf-preflight.php. PHP запускает отдельный процесс Python для анализа временной копии. Ghostscript для этой операции не нужен.

## Настройка хостинга

FTP переносит код сайта. На сервере под Linux установите Python 3.11+ и зависимости в отдельное окружение вне public_html.

```sh
python3 -m venv /path/to/pdf-preflight-venv
/path/to/pdf-preflight-venv/bin/python -m pip install -r tools/pdf-preflight/requirements.txt
```

Передайте процессу PHP переменную PDF_PREFLIGHT_PYTHON с абсолютным путём к python из этого окружения. При локальной работе в Windows можно указать абсолютный путь к установленному python.exe с библиотекой. Для PHP должен быть доступен proc_open. Если хостинг запрещает запуск процессов или установку Python, проверку нужно разместить на сервере, где эти возможности доступны.

Установите upload_max_filesize = 20M, post_max_size = 21M и лимит тела запроса на веб-сервере 21 МБ. Настройте доступные PHP для записи sys_temp_dir и upload_tmp_dir вне каталога сайта. Дайте веб-серверу достаточно времени на приём файла и до 15 секунд на обработку после загрузки.

Для публичного запуска используйте отдельный низкопривилегированный PHP-пул для API, без доступа к секретам сайта, с ограничением входящих запросов на веб-сервере. На Linux worker ограничен по памяти и времени CPU. PHP допускает одну проверку одновременно для этой установки. PHP удаляет временный PDF в конце обработки, включая ошибки. Оригинал остаётся у пользователя.
